# ADR-0001: 提取共享 Core 层

## 状态

已接受

## 背景

当前项目只有 CLI 模式，Agent 循环、内存管理、工具注册、LLM 调用都耦合在 cli.py 和 controller.py 中。需要新增 HTTP（Web Chat UI）模式，两种模式要共享核心逻辑。

## 决策

提取独立的 core 层，包含 AgentController、ConversationMemory、ToolRegistry、LLMClient。CLI 和 HTTP 各自作为前端调用 core。

## 理由

- 避免核心逻辑重复
- 两种模式的差异仅在 I/O 层（print vs SSE push）
- 为多会话支持提供清晰的边界

## 后果

- 需要重构现有代码，将模块从根目录移到 core/ 包
- CLI 和 HTTP 前端各自独立，可独立演进
- core 层不依赖任何前端框架
