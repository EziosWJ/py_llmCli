# ADR-0006: TOML 配置文件系统

## 状态

已接受

## 背景

LLM 连接参数（base_url、api_key、model）和运行时参数（temperature、max_tokens、memory_turns、max_tool_steps）需要持久化配置，避免每次启动手动设置。

## 决策

使用 TOML 格式配置文件，搜索顺序：

1. `./llmbox.toml`（当前目录，项目级配置）
2. `~/.config/llmbox/config.toml`（用户级配置）
3. 未找到则使用内置默认值

CLI 模式支持 `/set` 命令运行时修改；Web 模式支持 `PATCH /api/sessions/{id}/config` API。

## 理由

- TOML 是 Python 生态的标准配置格式（pyproject.toml），可读性好
- 两级配置（项目 + 用户）覆盖常见使用场景
- 运行时修改不影响配置文件，适合临时调试

## 后果

- 配置文件是可选的，零配置也能运行（连接 localhost:8080 的默认 llama.cpp）
- CLI 的 `/set` 修改仅影响当前会话，不写回文件
- Web 模式的配置覆盖是 per-session 的，新建会话仍继承全局默认值
