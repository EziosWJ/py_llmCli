# ADR-0003: Web Chat UI 使用轻量框架

## 状态

已接受

## 背景

需要为 llmbox 添加浏览器聊天界面。前端技术选型范围从纯 HTML/JS 到 React/Vue。

## 决策

使用 Alpine.js 或 htmx 轻量框架，FastAPI 直接 serve 静态文件，零构建步骤。

## 理由

- 聊天界面功能简单（输入框 + 消息列表 + 流式输出），不需要前端框架的复杂度
- 本地工具不需要独立的前端构建流程
- Alpine.js 的声明式绑定足以处理消息渲染和工具调用折叠展示
- 一个 HTML 文件即可部署

## 后果

- 不适合扩展为复杂的前端应用
- 如果未来需要更丰富的 UI（如文件上传、代码高亮），可能需要引入更多依赖
- 团队协作时前端开发体验不如 React/Vue
