# ADR-0005: Scheduler 定时任务系统

## 状态

已接受

## 背景

用户需要在对话中设置提醒（倒计时）和周期性任务（定时执行 shell 命令）。需要一个后台调度系统，独立于对话循环运行，并能将结果推送给用户。

## 决策

实现 Scheduler 类，基于后台守护线程，每秒检查一次任务列表：

- **TimerTask**: 一次性倒计时，到期后自动删除
- **CronTask**: 周期性 shell 命令，按固定间隔重复执行，可手动移除
- 通过 `NotificationCallback` 回调推送通知，CLI 和 Web 各自实现不同的通知方式

## 理由

- 后台线程方案实现简单，不引入外部依赖（如 APScheduler、Celery）
- 1 秒检查间隔足够满足倒计时精度需求
- 回调模式解耦了调度逻辑和通知渠道

## 后果

- 任务存储在内存中，进程重启后丢失
- CronTask 的执行结果（stdout/stderr/exit code）保留最近若干条，占用内存
- CLI 模式的通知在终端输出后可能被输入提示符覆盖，需要通过 stderr + bell 字符处理
- Web 模式需要维护 asyncio 队列，SSE 端点消费队列推送事件
